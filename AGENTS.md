# AGENTS.md

Project rules for agents and humans. The design document `docs/design/2026-10-25-ntbrowser-architecture-design.md` is normative; read it before changing `jsvm`, `netpolicy`, `dom` budgets or `app.clean`.

## Constraints

- Module path `nimbleterminal.dev/ntbrowser`; `go 1.26.8`; `go.mod` is spec Appendix B verbatim, including `replace charm.land/bubbletea/v2 => github.com/neomantra/bubbletea/v2 v2.0.0-20261020122444-536722b0bdb6` and `replace github.com/srwiley/rasterx => github.com/neomantra/rasterx v0.1.0` (retain the Bubble Tea fork for the WASM gate; a dependency's replaces do not apply here) and `require nimbleterminal.dev/nthtml v0.2.3`, `nimbleterminal.dev/ntfonts/cjk v0.3.1` (`loop/fonts_cjk.go`; `-tags nocjk` leaves it out), `nimbleterminal.dev/ntpicture v0.1.5`, `github.com/dop251/goja v0.0.0-20261105002551-2413f2132ac8`, `golang.org/x/net v0.62.0`, `github.com/charmbracelet/x/ansi v0.11.9`.
- Use published dependency versions without sibling-library replacements; keep `GOWORK=off`. The media helper retains its within-repository `replace nimbleterminal.dev/ntbrowser => ../..`.
- `THIRD_PARTY_NOTICES.md` is generated by `internal/tools/notices` from the modules `./cmd/ntbrowser` links; run `task notices` after any dependency change (`task check` fails when it is stale).
- The gates in `docs/design/2026-10-31-ntbrowser-profiles-content-design.md` §5 are every way out of the sandbox. A new way out adds a gate first; code reads the `profile.Profile`, whose zero value is closed.
- Native code lives only in `cmd/ntbrowser-media`, a nested module; `ntbrowser` links none (`TestMainDoesNotLinkNativeCode`). It pins `nimbleterminal.dev/ntvideo v0.5.0`.
- Every build and test runs with `GOWORK=off CGO_ENABLED=0` (Taskfile env, as in nthtml).
- `jsvm` and `dom` non-test files import none of `os`, `os/exec`, `net`, `net/http`, `syscall`, `io/fs`, `plugin`, `unsafe` (spec §6, enforced by `jsvm.TestNoSystemImports`).
- All Goja compilation goes through `goja.Parse(name, src, sandboxParserOptions()...)` + `goja.CompileAST`; never `goja.Compile`, `MustCompile`, `RunString`, `RunScript` in `jsvm` (spec decision table §6; `jsvm.TestOnlyHardenedCompilePath`).
- Page-controlled text reaches the terminal only through `app.clean` (spec decision 7).
- `nthtml.Model` is created with `nthtml.NewWithOptions(result, viewerOptions)` in `app` (ReflowTypeset off; `StableID` and zlib Kitty frames from the 2026-10-27 performance analysis: a re-flow or scroll step must not repaint the placeholder grid, `app.TestViewerKeepsKittyIDAndSendsZlib`); `document.Options.NoImage` stays false (spec §3, decision 19).

All rights reserved.`; Taskfile header comment `# ntbrowser - Copyright (c) 2026 Neomantra Corp.`.
- `GOOS=js GOARCH=wasm go build ./dom ./jsvm ./loop ./netpolicy ./subres ./profile ./content` must succeed (spec decision 14: compile-only in v1).
- Commit after every task; conventional-commit subjects (`feat:`, `test:`, `chore:`, `ci:`, `docs:`).
